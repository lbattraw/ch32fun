# ESC control with an automatic input probe

CH32V006 project based on `examples_x00x/adc_servo_sweep`. The ESC signal is the same 50 Hz pulse as that servo sweep. Instead of sweeping the pulse, this project arms the ESC at minimum throttle, learns the travel of the analog input, and then uses that input as the throttle.

The pulse is generated by TIM2, so `printf` and the ADC wait do not change the pulse width. `Servo.h` and `Servo.cpp` come from that example (ISC license, Servo commit `27b30675a200a4a856ba0e0eeaf7556e644fe4e1`).

## Pins

| Pin | Function |
| --- | --- |
| PC4 | Analog throttle, ADC channel 2. 0 V to 3.3 V. |
| PD4 | ESC signal. TIM2 CH1 in remap group 0. 1000 µs is idle, 2000 µs is full. |
| PD0 | Solid while arming, blinks 100 ms during the probe, blinks 500 ms while running. |
| PD1 | SWIO. Leave this for programming and debug `printf`. |

Give the ESC its own motor supply and tie the grounds together. The signal is 3.3 V. Remove the propeller before the first run.

## What it does

1. **Arm** (2 s). PD4 stays at 1000 µs so a typical hobby ESC can arm. The motor should stay stopped.
2. **Probe** (3 s). The pulse stays at 1000 µs. Move the analog input through its travel. The firmware records the lowest and highest 12-bit samples.
3. **Run.** Each 20 ms step maps the live sample across that span onto 1000–2000 µs. If the probe moved fewer than 64 counts, the map uses the full 0–4095 range instead.

## Use

```
make build
```

`make` programs the chip with minichlink. Debug `printf` lines are tagged `arm`, `probe`, and `run`.
